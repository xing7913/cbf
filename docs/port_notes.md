# ROS 2 实现与算法适配记录

本工程是独立的 ROS 2 工作空间实现，不包含旧中间件节点或旧构建文件。

## 已处理事项

1. **消息独立成包**：`SafeSetEllipsoidsConfig` 使用 `rosidl` 生成，包含 Header、生成时相机参考位姿、扁平化椭圆数据和列数。
2. **深度单位归一化**：`32FC1` 按米处理，`16UC1` 按毫米换算；零值、NaN 和无穷值按保守近距离处理。
3. **径向距离一致性**：椭圆生成使用 `z / |sin(theta)|`，避免把相机轴向深度直接当平面径向距离。
4. **相机原点**：消息携带相机安装位姿，并支持相机平面偏移参数。
5. **QP 控制边界**：线速度和角速度均有正、负边界，约束作用于最终控制量。
6. **无可行解保护**：输入超时、进入椭圆禁区、QP 不可行或数值错误时发布零速度。
7. **控制循环**：使用可配置 ROS 2 timer，默认 20 Hz。
8. **Gazebo Sim**：自带 SDF world 使用 Jetty 系统插件、DiffDrive 和深度相机，ROS 消息通过 `ros_gz_bridge` 映射。
